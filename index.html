设置 · Agent（大模型）接入
每家额度跟你的账号走，互不共享：智谱 Flash 系列不按 token 计费（只有频率限制）；硅基流动有常驻免费小模型（需实名，免费模型清单会轮换）；百炼新人每模型 100万 tokens、90 天有效；OpenRouter 免费档约 50 次/天。点按钮会自动填 Base URL 和模型名并打开注册页，Key 创建后粘贴到下方即可。
以 /v1 结尾。DeepSeek：https://api.deepseek.com/v1；通义：https://dashscope.aliyuncs.com/compatible-mode/v1；OpenAI：https://api.openai.com/v1
防 429 限流：两次请求的最小间隔；触发限流时会自动退避重试
免费引擎是公共翻译服务，仅供兜底：术语、公式、长难句质量明显不如 Agent，正式精读建议用 Agent 重译。
API Key 只存本机浏览器，不上传任何服务器。若提示 CORS/跨域错误，说明该 API 未开放网页直连，换 DeepSeek / 智谱 / 通义等即可。
♾️ 无限离线翻译方案：在本机装 Ollama（设置环境变量 OLLAMA_ORIGINS="*" 后重启）、LM Studio（开启 CORS 选项）或 llama.cpp 服务器（默认允许跨域），拉一个 Qwen3-8B 级别的模型，然后把上方 Base URL 填为 http://localhost:11434/v1（Ollama）或对应端口、模型名填本地模型名、Key 随便填一个非空值——完全离线、无任何额度限制，且质量远高于免费公共引擎。
