# 小唯阅读器 · 使用者指南

把论文读成小说。

你有没有过这样的体验：打开一篇 PDF，英文原文和中文翻译隔了十页，眼睛在两段之间来回跳；图表和公式被排版到页脚，看完文字还得翻回去找图；好不容易读到一句有启发的话，想记点想法，却要切到另一个笔记软件……

小唯阅读器就是为这些“小事”做的。它把一篇论文重新排成一条连续的阅读流：原文一段，译文紧跟一段；插图和公式回到它们本来该在的位置；你想划就划，想问就问，所有东西都留在你自己的电脑上。

---

## 三句话了解它

1. **像读小说一样读论文。** 自动识别单栏、双栏、标题、图表和公式，按阅读顺序重新排版，不再左右横跳。
2. **原文和译文贴在一起。** 英文句子和中文句子还能悬停联动：鼠标停在一句英文上，对应的中文就亮起来。
3. **划词、笔记、问 AI、生成报告都在同一页。** 不需要在 PDF 阅读器、翻译软件和笔记软件之间反复切换。

它不要求你注册账号，也不把你的论文传到任何服务器。解析、排版、存储都在本地完成。

## 30 秒开始

### 第一步：拿到它

按你的需要直接点链接：

- **在线网页版（不用下载）**：<https://2792009582-coder.github.io/XIAOWEI/>
- **安装版 exe（推荐，支持自动更新）**：[立即下载安装版](https://github.com/2792009582-coder/XIAOWEI/releases/latest/download/XiaoweiReader-1.0.1-setup.exe)
- **便携版 zip（解压即用，不自动更新）**：[立即下载便携版](https://github.com/2792009582-coder/XIAOWEI/releases/latest/download/XiaoweiReader-1.0.1-win-x64.zip)
- **查看所有历史版本**：[Releases](https://github.com/2792009582-coder/XIAOWEI/releases)

如果上面的直链因为发布新版而失效，进“查看所有历史版本”，拉到页面底部展开 **Assets** 手动选对应的文件。

网页版也可以离线用：把仓库里的 `index.html` 下载到本地再双击。如果双击没反应，右键 → 打开方式 → Microsoft Edge 或 Chrome；也可以运行同目录的 `双击启动-小唯阅读器.bat`。

注意：在 GitHub 网页里直接点 `index.html` 看到的是源码，这是 GitHub 的文件查看器，不是网页版。

### 第二步：打开一篇论文

点顶栏的「打开 PDF」，或者直接把 PDF 拖进阅读区。

解析器会在本地工作，把论文拆成一段一段，同时把插图、表格、公式和伪代码裁剪出来放回原位。第一次打开稍等几秒，之后再次打开同一篇会直接接着上次的进度。

### 第三步：开始读

- 想看中文：点「翻译全文」，或者只翻译当前段落。
- 想跳到某节：用左侧「目录」页签。
- 想找之前的标记：用左侧「标注」页签。
- 想换个亮度：点顶栏的太阳图标，在清爽白、护眼纸、夜间之间循环。

## 它最擅长的几个场景

### 场景一：赶文献综述

你手上有二十篇论文，每篇只想知道“它做了什么、新在哪里、怎么做的”。

点「Agent 分析」。它会在后台生成一份精读报告，包含：总结、创新点、研究方法、公式解析、同类文献推荐。你不用守着它，继续读当前的段落就行，报告好了会出现在弹窗里，还能导出成 Markdown。

### 场景二：啃一篇很难的论文

有些句子读三遍还是不确定意思。逐段中英对照配上句级联动就派上用场了：把鼠标停在英文句子上，对应的中文句子会灰底亮起；反过来也一样。术语和长难句不用靠猜。

### 场景三：边读边记

读到关键句，选中文字，浮出的调色盘提供四种颜色。写过的笔记会在高亮旁边留一个小笔标记，鼠标悬停就能看到当时写下的想法。

不需要“先复制、再打开笔记、粘贴、切回来”这一套动作。

### 场景四：带着问题读

选中一段原文，点浮出的问 AI 按钮，你的问题会自动带上这段上下文发出去。就算什么都没选，直接问，它也会把论文背景一起带上。

如果你只是想快速确认一个概念，用设置里的免费引擎就够了；想深入讨论，再换成自己的大模型 Key。

### 场景五：图表特别多的论文

论文里的图、表、公式、Algorithm 伪代码会被自动识别并裁剪成图片，插回原文对应的位置。图注单独成段，也可以翻译。读的时候不用再翻到文末找“Fig. 3”。

### 场景六：断网或者重视隐私

把网断掉，它照样能排版、阅读、高亮和整理文献库。翻译有免费公共引擎兜底；想完全离线又想要好质量，可以在设置里接入本机的 Ollama、LM Studio 或 llama.cpp。

## 界面长什么样

```text
顶部：打开 PDF / 翻译全文 / Agent 分析 / 问 AI / 导出对照 / AI 排版 / 主题 / 设置
左侧：文献库 | 目录 | 标注
中间：像小说一样连续排列的原文与译文
底部：细进度条，告诉你这篇读到哪了
```

选中文字后会浮出小工具条：四种高亮颜色，以及「问 AI」。

点右上角设置，可以：

- 一键接入免费大模型（推荐智谱 GLM-4-Flash，注册即用，该模型永久免费）
- 填自己的 OpenAI 兼容接口（DeepSeek、硅基流动、百炼、OpenRouter 都支持）
- 检测本机已经跑起来的模型服务
- 测试连接、调整并发和请求间隔
- 检查更新、查看关于（安装版）

备份和导入在左侧「文献库」页签的底部，按钮叫「备份全部」和「导入备份」。

## 让 AI 更好用的几个小技巧

- **免费引擎先顶上。** 设置里的「免费引擎一键接入」会自动填好地址和模型名，你只需注册并粘贴自己的 Key。Key 只存在本机。
- **别催太狠。** 并发数和请求间隔默认已经比较保守。如果遇到 429 限流，把间隔调大一点，比反复重试更省时间。
- **问得越具体越好。** “这段的假设是什么”比“解释一下”更容易得到有用的回答。
- **想要无限额度，就用本地模型。** 设置里点「检测本地模型」，连通后把 Base URL 和模型名填进去，翻译和分析全走本机，没有额度限制。
- **AI 排版是可选的。** 本地解析已经能用；如果你发现标题误判、段落被拆开，再点「AI 排版」让模型审校一次。它失败时会自动保留原来的本地排版。

## 你的数据在哪里

这点值得单独说清楚。

- 文献、阅读进度、译文、高亮、笔记、问答记录都存在你自己电脑的浏览器 IndexedDB 里；桌面版存在本地用户目录。
- 设置里的 API Key 也存在本机，不会上传到这个项目任何地方。
- 没有账号系统，没有服务器，没有遥测。
- 想换电脑：在左侧「文献库」页签底部点「备份全部」，生成 JSON 文件；新电脑上点「导入备份」选这个文件即可。
- 桌面版更新不会清掉你的文献库。

卸载桌面版不会自动删除你的文献数据；以后重装，文献库还在。想彻底清理才需要手动删除本地用户目录里的应用数据。

## 常见问题

### 什么样的 PDF 能用

需要**文字版** PDF。纯扫描的图片 PDF 没有可提取的文字，解析不出来。如果一本书是扫描版，可以用 OCR 工具先转成文字版。

### 为什么更新了程序，旧论文还是要重新拖入

解析引擎升级后，旧文献库里保存的还是旧版解析结果。删掉那条记录，重新拖入 PDF，才能吃到新的排版逻辑。新拖入的论文不受影响。

### 翻译很慢或者报 429

这说明免费引擎或你的接口在限流。可以在设置里调大「请求间隔」、调小「并发请求数」，或者换一个引擎。智谱 GLM-4-Flash 不按 token 计费，但仍有频率限制。

### 公式显示成了原始文本

大部分公式会用 KaTeX 渲染。少数期刊的公式字体和正文同族，无法可靠区分，会以“数据行”形式呈现。遇到这种情况，原文仍然保留，不影响阅读。

### 高亮颜色能改吗

选中已有高亮，弹出的小菜单可以改颜色、编辑笔记或删除。

### 安装版和便携版怎么选

安装版支持自动更新，推荐日常使用。便携版解压即用、不写注册表，适合放在 U 盘里临时用；但它不会自动更新，需要自己去 Releases 重新下载。

### Windows 提示“未知发布者”

安装包没有代码签名证书，所以系统会提示。点“更多信息 → 仍要运行”即可。如果所在机构对安全性要求很高，可以等后续配置签名证书。

### 怎么更新

安装版启动 6 秒后会静默检查；也可以按 `Alt` 调出菜单 → 帮助 → 检查更新，或者打开设置 →「检查更新」。发现新版后会后台下载，按钮变成「安装 vX.X.X」，点击后重启生效。
